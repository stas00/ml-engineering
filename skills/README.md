# Skills

Agent skills for this book. Copy a `SKILL.md` into your agent's skills directory, or point the agent at the GitHub URL.

- [Machine Learning Engineering](ml-engineering/SKILL.md) — train and operate large-scale ML models (accelerators, storage, network, orchestration, throughput, instabilities, checkpointing, inference). Canonical: https://github.com/stas00/ml-engineering/blob/master/skills/ml-engineering/SKILL.md
- [Evaluate a GPU cluster](evaluate-cluster/SKILL.md) — trial-node / acceptance loop: environment dump, sequential matmul FLOPS, intra- and inter-node all-reduce, `fio-scan` on local disk and shared FS, dated markdown report. Canonical: https://github.com/stas00/ml-engineering/blob/master/skills/evaluate-cluster/SKILL.md

The repo-root [`SKILL.md`](../SKILL.md) is a redirect to the Machine Learning Engineering skill.

Companion skills in other books: [The Art of Debugging](https://github.com/stas00/the-art-of-debugging/blob/master/SKILL.md), [Stas' Python Cookbook](https://github.com/stas00/python-cookbook/blob/master/SKILL.md).
